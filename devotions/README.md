# Daily Devotions

This folder contains daily devotion text files for the Devotion tab.

## File Naming Convention

Devotion files should be named using the format: `day-XXX.txt` where XXX is the day of the year (001-365).

Examples:
- `day-001.txt` - January 1st
- `day-032.txt` - February 1st
- `day-365.txt` - December 31st

## File Format

Each devotion file is a plain text file. The app will automatically format:
- Line breaks are preserved
- Empty lines create paragraph breaks
- Text is displayed with proper spacing and readability

## Adding Devotions

Simply create text files following the naming convention above. The app will automatically load the appropriate file based on the current day of the year.

You can add devotions for any day of the year. If a file doesn't exist for a particular day, the app will display a message indicating that no devotion is available for that day.
